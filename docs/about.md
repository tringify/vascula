# About Vascula

Vascula is a template language and Go library made by
[Tringify](https://tringify.com).

## Licence

Vascula and this documentation are released under the MIT licence.
Copyright 2026 Tringify.

## Security

Report a suspected vulnerability privately to **developers@tringify.com**,
with the Vascula version, a minimal template and the options involved. Please
do not report vulnerabilities in public. See [Safety and limits](/safety) for
what Vascula protects against.

## Contact

Questions and feedback: **developers@tringify.com**.

## The name

*Vascula* is Latin-ish for "little vessels": the veins that carry what a page
needs to where it is needed.
